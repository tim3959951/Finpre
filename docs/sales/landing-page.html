成績單

我們從 Google TimesFM 出發，最後讓數字決定用誰

同一套 walk-forward 引擎（模型只看得到預測當下以前的資料）比較了基礎模型、統計基準與本地訓練模型。2018–2026 的結果，每月重訓的 LightGBM 在四個市場／天期都勝出，所以它是現在的 champion；TimesFM 2.5 的強項是區間校準，保留為基準與退回模型。

台股 5 日+1.77%49/50 檔勝出 · 80% 區間覆蓋 78%
台股 20 日+3.01%44/50 檔勝出 · 覆蓋 76%
美股 5 日+0.81%48/50 檔勝出 · 覆蓋 78%
美股 20 日+0.61%37/50 檔勝出 · 覆蓋 75%

對照：TimesFM 2.5（zero-shot）同期為 −1.02%、−1.56%、−2.11%、−3.26%，80% 區間覆蓋 77–83%。上線後的每一筆預測也每天自動計分，公開在產品的成績單頁。

註

選股排序：統計上有效，扣成本後不賺錢。逐日選出上市流動性前 50 大，LightGBM＋籌碼的每週 IC 約 0.03（t ≈ 3.4），9 年中 7–8 年為正。但扣掉每次來回 58.5 bps 的手續費與證交稅後，前 10 名組合沒有勝過等權持有。

所以在 Finpre 裡它叫「研究清單」，用來縮小研究範圍，而且這個結果直接印在每一份每日報告上。我們也不賣擇時訊號：長期回測中它沒有贏過買進持有。

功能

研究、風險、報告，一套引擎

多代理個股研究

輸入代號，10–30 秒得到三位分析師的報告與整合結論。

  • 技術：均線、KD、MACD、量價、ADX
  • 基本面／籌碼：月營收、本益比百分位、三大法人、融資券、新聞情緒
  • 量化：未來 5／20 日報酬率分位數與上漲機率

風險雷達

輸入持股，看到組合最壞會怎樣、風險集中在哪裡。

  • 報酬區間、95% VaR 與 ES
  • 集中度、產業、平均相關係數
  • 各持股的尾端損失貢獻、美元匯率

每日盤後報告

收盤後自動產生，HTML／Markdown 可直接轉發會員或 LINE。

  • 市場狀態燈號（多頭／盤整／空頭）
  • 研究清單排名＋扣成本揭露
  • 觀察清單的未來報酬區間與法人動向

API 與白標

同一套能力用 REST API 整合進你的系統。

  • API 金鑰、方案計量，失敗不扣額度
  • 稽核紀錄匯出（JSON Lines）
  • 報告換成貴公司品牌

合規

合規寫在程式裡，不靠提醒 AI 要守規矩

依《證券投資信託及顧問法》，對不特定人提供個股買賣建議屬投資顧問業務。Finpre 預設的研究模式在輸出前逐句檢查：全形、簡體、夾空白或隱藏字元的寫法先還原，再移除建議用語與價位。法人買賣超這類事實保留。試試看：

研究模式（預設）顧問模式
適用對象所有非持牌客戶企業版且持有證券投資顧問事業許可的機構
輸出訊號、分數、信心、報酬率區間（%）、波動、模型成績另含動作、部位、進場、停損、停利
稽核每一筆輸出寫入 HMAC 雜湊鏈稽核紀錄並每日錨定；被過濾的內容只留在稽核紀錄，可匯出給法遵

聯絡窗口於正式上線時公布。

Finpre 為投資研究工具，內容由統計模型與 AI 根據公開資料自動產生，僅呈現訊號、機率與歷史回測結果，不提供個股買賣建議、買賣價位或持股配置建議，亦不構成任何要約。投資有風險，過去績效不代表未來表現。顧問模式僅提供予持有證券投資顧問事業許可之機構，由該機構對其客戶之建議負責。
