# Finpre Demo 腳本（20 分鐘，對象：投顧／券商研究主管＋法遵）

準備：`docker compose up -d`；用 `manage_tenants.py` 建立兩個租戶——「示範研究版」（research）與「示範投顧」（enterprise、licensed、advisor）；前一天跑過 `daily_job.py --market TW`。

## 0. 開場（2 分鐘）
「市面上的 AI 選股工具給你結論；Finpre 給你結論，**加上這個模型過去的成績單**。今天看四件事：研究、風險、報告、合規。」

## 1. 個股研究（5 分鐘）
1. 以研究版金鑰登入網頁 → 個股分析 → 輸入 `2330` → 執行。
2. 指出：綜合訊號、信心、未來 5 日報酬率 80% 區間；三位分析師各自的分數與理由；新聞以引述標示。
3. 「報酬率分布圖」：這是機率分布，不是目標價。
4. 研究助理頁問：「2330 可以買嗎？停損設多少？」→ 系統說明它是研究工具，改提供訊號與風險資訊。**這句話就是給法遵看的。**

## 2. 風險雷達（4 分鐘）
1. 輸入一個客戶持股（例如 2330、2317、2454、NVDA 各若干股）。
2. 看 5 日 VaR／ES、虧損超過 5% 的機率、集中度警示、哪一檔貢獻最多尾端損失、美元資產的匯率影響。
3. 「理專每週跟客戶談持股，用這頁開場。」

## 3. 每日報告與成績單（4 分鐘）
1. 每日報告頁 → 產生台股報告 → 下載 HTML（可直接寄給會員或轉 LINE）。
2. 成績單頁：2018–2026 各年度表現、模型在空頭／盤整期的表現、上線後追蹤；**排名扣成本後的結果**也在這裡。
3. 「我們不藏失敗的年份。這是為什麼您的客戶可以信任它。」

## 4. 合規與整合（4 分鐘）
1. 改用企業版（持牌）金鑰 → 同一檔股票出現顧問模式的動作、部位與價位 → 由貴公司對客戶負責。
2. API：`/docs` 展示 `analyze`、`portfolio/risk`、`report`；`/v1/audit/export` 匯出稽核紀錄（JSON Lines、HMAC 雜湊鏈、每日錨點）。
3. 維運：Docker 一鍵部署、方案計量、失敗不扣額度。

## 5. 收尾（1 分鐘）
提出 30 天試用：用貴公司的股票池跑一份回測成績單＋白標報告樣本，兩週內交付。

## 常見問題
- **準確率多少？** 用 CRPS 衡量機率預測：台股 5 日比 random walk 好 1.8%，50 檔中 49 檔勝出；80% 區間實際覆蓋 75–78%。方向預測沒有可靠優勢，我們不賣擇時訊號。
- **選股能賺錢嗎？** 排序與未來報酬顯著相關（IC 0.03），但扣除台股交易成本後前 10 名沒有勝過等權組合。它適合縮小研究範圍，不適合當買進清單。
- **資料來源？** 試用期使用公開資料；正式合約會改用授權資料源（TEJ／CMoney／FinMind 付費方案等）。
- **LLM 會亂講嗎？** 數字由規則引擎與模型先算好，LLM 只能引用、在 ±0.5 內調整分數；所有輸出經過合規過濾並寫入稽核。
