# Finpre｜每個訊號都附成績單的 AI 投資研究引擎

**給誰**：證券投資顧問事業、券商研究部、投信研究團隊、財經內容團隊。

**解決什麼**：研究人力有限，每天要產出個股與盤勢報告；AI 工具多半只給結論，無法說明「這個模型過去準不準」，法遵也無法稽核它說過什麼。

## 我們提供

| | |
|---|---|
| **多代理個股研究** | 技術、基本面／籌碼／情緒、量化三位 AI 分析師平行分析，首席分析師整合成訊號、信心與未來 5／20 日報酬率區間；約 10–30 秒一檔 |
| **風險雷達** | 輸入客戶持股，得到組合的報酬區間、VaR／ES、集中度、相關性、各持股的尾端損失貢獻（含匯率） |
| **每日盤後報告** | 收盤後自動產生：市場狀態、研究清單排名、觀察清單風險區間、模型成績單；HTML／Markdown 可直接轉發 |
| **公開成績單** | 2018–2026 walk-forward 回測＋上線後每日自動計分，失敗的年份與扣成本後的結果照實揭露 |
| **合規與稽核** | 研究模式在程式輸出端強制移除買賣建議與價位；持牌機構可開啟顧問模式；每筆輸出寫入防竄改稽核紀錄，可匯出給法遵 |
| **API／白標** | REST API、方案計量、稽核匯出；報告可換成貴公司品牌 |

## 經過驗證的數字（2018-01 → 2026-09，walk-forward，每月重訓）

- 機率預測比 random walk 更準：台股 5 日 +1.8%（50 檔中 49 檔勝出）、台股 20 日 +3.0%、美股 5 日 +0.8%（48/50）。
- 80% 預測區間的實際覆蓋率 75–78%，適合用於風險管理與部位控管。
- 台股選股排序：每週 IC 約 0.03（t ≈ 3.4，統計顯著）。**扣除交易成本後，前 10 名組合沒有勝過等權組合**——我們把它定位為研究篩選工具，並在每份報告揭露這一點。
