# Finpre 產品規劃（v1.0）

> 產品經理觀點的規劃文件：要賣給誰、賣什麼、怎麼合法地賣、怎麼定價、怎麼證明它有用。
> 最後更新：2026-10-01。本文件的法規內容是產品規劃用的整理，不是法律意見，上線前須由熟悉證券法規的律師確認。

## 1. 一句話定位

**Finpre：每個訊號都附成績單的 AI 投資研究助理。**
四位 AI 分析師（技術、基本面／籌碼、量化、首席顧問）幫你看台股與美股，而每一個數字都能追溯到「這個模型過去在這檔股票、這種市場狀態下的真實回測表現」。

市面上的 AI 選股工具多半只給結論；Finpre 的差異是**可驗證**：walk-forward 回測、區間校準、選股 IC、壓力事件表現全部公開，量化 Agent 會依模型在該標的的歷史技能自動調低不可靠的訊號。

## 2. 我們從回測學到、而且敢拿來賣的東西

產品只包裝經過驗證的能力（詳見 `docs/ARCHITECTURE.md` §11）：

| 能力 | 證據 | 產品化方式 |
|---|---|---|
| 機率預測區間（未來 5／20 日的 P10–P90） | 每月重訓的 LightGBM 在 2018–2026 勝過 random walk：台股 5 日 49/50 檔、美股 5 日 48/50 檔；80% 區間實際覆蓋 75–78%（TimesFM 2.5 為 77–83%） | **風險雷達**：持股的未來區間、組合 VaR／ES、最壞情境 |
| 市場狀態判斷 | 各模型在多頭／空頭／盤整的表現差異大，且可在當下判定 | 每份報告開頭的「市場狀態燈號」與依狀態調整的信心 |
| 台股橫斷面排序 | 上市流動性前 50（逐日選取）每週 IC 約 0.03（t = 3.4–3.9），9 年中 7–8 年為正；**但扣 58.5 bps 成本後前 10 名沒有勝過等權組合** | **研究清單**：分數排名＋歷史成績＋成本揭露，用來縮小研究範圍，而不是買進清單 |
| 誠實的成績單 | 同一套回測引擎可每日重跑、shadow 模式記錄每一筆線上預測 | **成績單頁**：模型的即時命中率、校準、IC，公開給所有用戶 |

**不賣**的東西（證據不支持）：擇時買賣訊號（長期沒有贏過買進持有）、「保證報酬」、未扣成本的選股績效、「跟著排名買就會贏」——排名扣成本後的結果直接印在每份報告上。

## 3. 目標客群與要解決的問題

| 客群 | 他們的工作 | 痛點 | Finpre 給的價值 |
|---|---|---|---|
| **A. 持牌投顧／券商研究部／投信** （主要營收） | 每天產出個股與盤勢報告、服務會員 | 分析師人力貴、報告格式重複、缺量化佐證 | API＋白標報告＋完整建議模式；稽核紀錄可直接交法遵 |
| **B. 專業個人投資人**（中高資產、工程師、自營交易員） | 自己研究、管理持股風險 | 資訊散、看不出哪個指標真的有用 | 研究模式：多代理研究報告、風險雷達、排名與成績單 |
| **C. 財經內容創作者**（YouTube、Podcast、電子報） | 每天產內容 | 需要可信的數據與圖表 | 每日盤後研究報告、可引用的圖表 |

第一年主攻 **A**（合規且單價高），用 **B** 建立口碑與成績單的公信力。

## 4. 合規設計（這決定產品長什麼樣子）

台灣《證券投資信託及顧問法》：對不特定人提供個股的價值分析或買賣建議並收費，屬證券投資顧問業務，須取得許可；SITCA 的問答也指出，提供個股買賣價位、支撐壓力、停損停利的 App 可能構成未經許可的投顧業務。因此產品分兩種**模式**，由設定檔決定，程式強制執行：

| | 研究模式 `research`（預設，對一般用戶） | 顧問模式 `advisor`（僅限持牌機構） |
|---|---|---|
| 對象 | 個人付費用戶、內容創作者 | 持牌投顧、券商、投信（合約約定由其負責建議） |
| 輸出 | 訊號偏多／偏空、分數、機率、報酬率區間（%）、歷史成績 | 另含買進／賣出、建議部位、停損／停利價位 |
| 禁止 | 買進、賣出、加碼、減碼、目標價、停損、停利、建議部位等字眼，以及以價格表示的操作價位 | – |
| 強制方式 | 決策引擎不產生行動與價位欄位；LLM 提示詞禁止；**輸出前再做一次語言過濾**；違規時改寫並記錄 | – |
| 紀錄 | 每一次輸出寫入稽核紀錄（時間、用戶、模式、輸入、輸出雜湊） | 同左，可匯出給法遵 |

未來取得自有投顧許可（實收資本額至少新台幣 2,000 萬元）後，可直接對個人開放顧問模式。

## 6. 定價

以財報狗（NT$599–799／月）與 FinLab VIP（約 NT$6,000／年）為個人市場的價格錨點，企業版以取代 0.5–1 位分析師人力定價。

| 方案 | 價格 | 內容 | 模式 |
|---|---|---|---|
| 免費 | NT$0 | 每日 3 次個股分析、成績單、每日報告（排名只顯示前 5 名）、觀察清單與風險雷達各 5 檔 | 研究 |
| 研究版 | NT$690／月；NT$6,900／年 | 每日 50 次分析、觀察清單 30 檔、風險雷達、完整每日報告與排名 | 研究 |
| 專業版 | NT$1,990／月 | 研究版全部＋API 每月 5,000 次、觀察清單 200 檔、報告匯出 | 研究 |
| 企業版（持牌機構） | NT$60,000 起／月 | 顧問模式、白標報告、API 每月 20 萬次、稽核紀錄匯出、專屬股票池、SLA | 顧問 |

程式中的方案限制在 `fintech_agent/product/plans.py`。

## 8. 風險與對策

| 風險 | 對策 |
|---|---|
| 被認定為未經許可的投顧業務 | 預設研究模式、程式強制語言過濾、稽核紀錄；企業版合約由持牌機構負責建議；上線前律師審閱 |
| 資料授權（yfinance 不可商用） | 上線前改用授權資料源；資料層已抽象化，替換只需新的 `DataProvider` |
| 模型失效（市場結構改變） | 每月重訓、每週自動重跑 benchmark、成績單公開、技能折減自動降權 |
| LLM 幻覺 | LLM 只能引用系統預先算好的數字；分數由規則引擎決定，LLM 只能在 ±0.5 內調整 |
| 客戶期待「穩賺」 | 行銷只使用扣成本、逐日選股的回測數字；成績單同時顯示失敗的年份 |

## 9. 上市計畫

1. **第 0–1 個月**：v1.0 上線封測，邀請 20 位專業個人用戶；每週公開成績單。
2. **第 1–3 個月**：接洽 10 家中小型投顧／券商研究部，提供 30 天企業版試用與白標報告樣本。
3. **第 3–6 個月**：LINE 推播、金流、授權資料源；簽下首批 3 家企業客戶。
4. **第 6–12 個月**：評估申請自有投顧許可，開放個人顧問模式。

| 嚴重度 | 數量 | 代表性問題 | 修正 |
|---|---|---|---|
| 合規洩漏 | 7 | API 回傳被刪除的建議原文；不含關鍵字的價位（「下檔關注 950 元」）；LLM 用巢狀結構繞過；價格圖顯示預測價位；簡體／全形／空白繞過；分析師目標價出現在證據中 | 被刪內容只進稽核；價位偵測（幣別＋目前股價 ±50%）；巢狀與字典鍵都過濾；研究模式改畫報酬率分布；輸入正規化；目標價欄位移除、專家人設改寫 |
| 安全 | 5 | 網頁無認證且公開顯示他人稽核紀錄；工作階段共用分析結果；計量與稽核在並發下失效；免費方案從報告端點拿到完整排名 | API 金鑰登入；每個工作階段獨立；IMMEDIATE 交易；HMAC＋每日錨點；報告套用方案限制 |

| 小問題 | 4 | HTML 未跳脫欄位、對話工具參數無上限、排程不認得休市日、無法撤銷持牌／換發金鑰 | 全部修正 |

驗收標準（每次推送由 CI 執行）：`pytest`（含 `tests/test_hardening.py` 的繞過與誤殺案例）、`scripts/compliance_check.py`（對抗式 LLM 對分析、對話、組合、報告全部輸出做檢查）。每日排程也會掃描發布的報告檔並驗證、錨定稽核紀錄。

## 11. 賣點（給業務與行銷）

1. **成績單就是產品**：其他工具給結論，Finpre 給「這個模型過去在這種市場的真實表現」，包括失敗的年份與扣成本後不賺錢的結果。誠實本身就是差異化。
2. **合規內建，不靠自律**：研究模式的限制寫在程式的輸出邊界、經過對抗式測試，加上防竄改的稽核紀錄——投顧與券商的法遵可以直接拿來用。
3. **風險先於報酬**：風險雷達回答「我的持股組合最壞會怎樣、風險集中在哪裡」，這是模型證據最強的部分（80% 區間實際覆蓋 75–78%）。
4. **台股在地**：三大法人、融資券、月營收、漲跌幅制度、台股慣用術語；逐日選股的回測避免存活者偏差。
5. **開放整合**：同一套能力透過 API、網頁、每日報告（HTML／Markdown，可直接轉發 LINE／Email）提供；企業版可白標。
